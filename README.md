**The problem**

After meetings, managers often need to manually turn discussion notes into tasks, assign owners and deadlines, and break large tasks into actionable steps. Tracking progress across projects can also become time-consuming.

**Solution workflow**

```mermaid
flowchart LR
    A["Meeting transcript"] --> B["AI extracts tasks"]
    B --> C["Editable preview"]
    C --> D["Human approval"]
    D --> E["Bulk-create tasks"]
    E --> F["AI sub-tasks"]
    E --> G["n8n notifications"]
    G --> H["Slack"]
    E --> I["Productivity analytics"]

    classDef cyan fill:#0D1117,stroke:#22D3EE,stroke-width:2px,color:#22D3EE
    classDef violet fill:#0D1117,stroke:#A855F7,stroke-width:2px,color:#A855F7
    classDef pink fill:#0D1117,stroke:#EC4899,stroke-width:2px,color:#EC4899
    classDef green fill:#0D1117,stroke:#10B981,stroke-width:2px,color:#10B981

    class A cyan
    class B,F violet
    class C pink
    class D,E green
    class G,H,I cyan
```

**Key features**

- **Transcript-to-Tasks Pipeline:** Uses AI to extract structured tasks, assignees, and deadlines from meeting transcripts. Users review and approve tasks before bulk creation.
- **AI Task Decomposition:** Breaks complex tasks into smaller, actionable sub-tasks.
- **Team and Project Management:** Supports project collaboration, task tracking, and productivity insights.
- **Automated Notifications:** Uses n8n and Slack integrations to send task updates.
- **End-to-end Development:** Built the REST API and responsive frontend with dark/light mode.

**Impact**

- Reduced ~70% manual task creation time post-meetings.
- Processes 30-min meeting transcripts in &lt;20s.
